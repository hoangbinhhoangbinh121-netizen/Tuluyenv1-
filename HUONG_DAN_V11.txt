TIÊN GIỚI BOT v11.0 — HƯỚNG DẪN & GHI CHÚ THAY ĐỔI
==================================================

V11.0 so với v7: (a) index.js tự kiểm tra và cài lại thư viện khi discord.js thiếu file (lỗi WebhookClient);
(b) zip đủ src/data (lỗi REALM_SPEED_MULT); (c) /nhapdb nhập dữ liệu cũ; (d) scripts/redeploy.sh giữ token + DB;
(e) emoji theo sprite mới (prefix tg7_ giữ nguyên, 146 emoji đã tải được trên host của bạn).

(f) NGUYÊN NHÂN THẬT của "người khác tu luyện không được": bảng sects thiếu cột exp_buff_until/treasury/title
    -> mọi người đã vào tông môn đều lỗi "no such column: exp_buff_until" khi tu luyện/đóng quan. Đã thêm cột vào
    migration (tự chạy khi khởi động, DB hiện có được vá luôn) và làm tu luyện không còn bị chặn nếu DB phụ lỗi.

1. CÀI ĐẶT NHANH
   - Node.js >= 22.5 (dùng node:sqlite) hoặc có better-sqlite3.  npm install
   - Sao chép .env.example -> .env, điền DISCORD_TOKEN (+ GUILD_ID để lệnh slash hiện ngay).
   - npm start
   - Lần chạy đầu bot tự tải ~127 emoji pixel lên "Application Emoji" của bot (tên tg7_<key>).
     Nếu bị giới hạn tốc độ, phần còn lại tải nền; trong lúc đó dùng emoji Unicode dự phòng.
   - Lệnh /datkenhthegioi (admin) chọn kênh để bot đăng thông báo thế giới (boss, thiên kiếp...).

2. EMOJI PIXEL (MỚI — dùng bộ sprite do bạn gửi)
   - Nguồn: assets/source/sprite_sheet.png (+ sprite_boxes.json = toạ độ từng ô "hàng.cột").
   - Cắt tự động:  python3 scripts/build_emoji_from_sheet.py [--preview]
     (cần Pillow, numpy, scipy). Bảng ánh xạ key -> ô nằm ở đầu file script (biến MAP) — muốn
     đổi icon nào chỉ cần sửa số ô rồi chạy lại.
   - Mỗi icon: 128x128, nền trong suốt, vừa khung 112px => cỡ đồng đều.
   - Giữ nguyên icon vẽ sẵn cho: thanh bar_* / warbar_* (ô thanh tiến trình) và 7 ký hiệu chức năng
     (dongmenu ✕, tuchoi ✕, xacnhan ✓, thamgia ＋, lammoi ↻, nangcap ⬆, thongtin ℹ, doiten ✎) vì sprite không có.
   - 15 cảnh giới dùng canhgioi_0..14 (Phàm Nhân -> Tiên Đế); phẩm chất rar_* dùng cờ hiệu 5 màu.
   - Đổi bộ icon xong: xoá emoji tg7_* cũ trong Developer Portal (Application > Emojis) HOẶC
     đổi PREFIX trong src/game/emoji.js (vd tg8_) để bot tải bộ mới; xoá data/emoji_ids_v7.json.
     (Discord không cho ghi đè ảnh của emoji đã tồn tại.)

9. CẬP NHẬT BẢN MỚI, GIỮ TOKEN CŨ (unzip + deploy lại)
   Trong thư mục bot đang chạy (có .env và data/):
       bash scripts/redeploy.sh tien-gioi-bot-v11.zip      (hoặc: npm run redeploy -- tien-gioi-bot-v11.zip)
   - Giải nén đè mã nguồn, GIỮ NGUYÊN .env (token), data/ (DB), logs/, node_modules/.
   - Tự sao lưu .env + data vào .redeploy_backup/<thời gian>, chạy npm install, rồi restart PM2 nếu có
     (không có PM2 thì tự khởi động lại bằng cách bạn đang dùng). NO_RESTART=1 để bỏ qua bước restart.
   - Lần đầu từ bản cũ chưa có script: giải nén zip ra thư mục tạm, chép scripts/redeploy.sh vào bot rồi chạy như trên,
     hoặc đơn giản: giải nén đè thủ công và KHÔNG xoá .env + data/.

10. LỖI "Cannot find module '../client/WebhookClient'"
   Do thư viện discord.js trên host cài dở/bị dọn file. index.js nay tự kiểm tra lúc khởi động và tự cài lại
   (xoá node_modules/discord.js rồi npm install). Nếu vẫn lỗi: xoá thư mục node_modules, bấm Restart để host cài lại.

11. LỆNH CHỮ — TIỀN TỐ (PREFIX) ! VÀ ?
   Trong game gõ /lenhchu (hoặc !lenhchu) để xem bản hướng dẫn ngay trong bot.
   - Mọi lệnh / đều gõ được như tin nhắn thường: !tuluyen  ?dongquan  !dotpha  ?danhboss  !huongdan ...
     Tên lệnh giống hệt lệnh /, không phân biệt hoa thường. Tiền tố mặc định: ? và !  (đổi bằng COMMAND_PREFIX=?,!,.)
   - Lệnh có tham số: gõ các giá trị theo ĐÚNG THỨ TỰ của lệnh /, cách nhau dấu cách.  Ví dụ:  !usedb 1
     Người chơi: @tag hoặc dán ID.  Số lớn: 1.000.000 hoặc 1000000.
   - Lệnh cần file (nhapdb, restore_db): đính kèm file .db trong CÙNG tin nhắn rồi gửi: !nhapdb  (admin).
   - Lệnh admin (trieuhoiboss, huyboss, datkenhthegioi, backupdb, listdb, usedb, nhapdb...) gõ được bằng tiền tố,
     nhưng chỉ admin dùng được. Admin gõ !hoang để nhận danh sách lệnh admin ẩn của Tông Môn Chiến
     (!tongmonchien_start / _stop / _reset / _addpoint / _debug) — bot nhắn riêng cho bạn.
   - Không thấy bot trả lời:
       * Bật "Message Content Intent" ở Discord Developer Portal -> Bot (bắt buộc cho lệnh chữ).
       * ENABLE_PREFIX_COMMANDS=1 (mặc định) và COMMAND_PREFIX đúng.
       * Bot cần quyền Xem kênh, Gửi tin nhắn, Nhúng liên kết trong kênh đó.
       * Gõ sát tiền tố: "!tuluyen" (không phải "! tuluyen").
       * Không chắc thì dùng lệnh /, luôn hoạt động.
